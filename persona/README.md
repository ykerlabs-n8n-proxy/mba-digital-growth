# Persona-hipótese com IA (aula 1)

Atividade valendo 25 pontos. Entrega em PDF: capa + 3 páginas, com nome, data e link público do chat no cabeçalho da página 1.

## Arquivos desta pasta

- `ficha.md`: ficha do produto, 8 linhas, escrita pelo aluno.
- `prompt.md`: prompt usado e as duas rodadas de perguntas (a criar).
- `retrato.md`: síntese, retrato e validação (a criar).
- `leitura-critica.md`: o que manter, o que é frágil, próximo passo (a criar, escrito pelo aluno).

## Critérios de avaliação

| Critério | Pontos |
|---|---|
| Origem honesta | 5 |
| Dor, JTBD e cena | 5 |
| Validação | 6 |
| Antipersona | 3 |
| Leitura crítica | 6 |
